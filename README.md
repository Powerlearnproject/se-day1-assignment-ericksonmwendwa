#Part 1: Introduction to Software Engineering

Explain what software engineering is and discuss its importance in the technology industry.
- Software engineering is a discipline that applies engineering principles to the design, development, testing, and maintenance of software
- It's important because it's needed to make all the technology we use work reliably.


Identify and describe at least three key milestones in the evolution of software engineering.
- Making order: In the early days, software was messy. People figured out ways to organize it better.
- Working fast: With the internet, we needed to make software quickly, so we learned to work in shorter, faster cycles.
- Using objects: This made it easier to build big programs by using reusable parts.


List and briefly explain the phases of the Software Development Life Cycle.
- Planning: This is the initial stage where the project's goals, scope, and feasibility are determined. Essentially, what the software needs to do, and if it is possible to make it.
- Design: In this phase, the software's architecture is created. This includes designing the user interface, database, and overall structure of the software.
- Implementation: This is where the actual software code is written. Developers translate the design into a working program.
- Deployment: The software is released to the users. This might involve installing it on computers or making it available online.
- Maintenance: After deployment, the software is maintained to fix any issues, provide updates, and add new features. This is the ongoing support of the software.


Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.
- The Waterfall methodology follows a linear, sequential approach, where each phase of a project must be completed before the next one begins. This structured method excels in scenarios with well-defined requirements and minimal anticipated changes, such as large-scale construction projects or government initiatives with strict regulatory compliance. In contrast, the Agile methodology embraces iterative development and flexibility, allowing for adjustments throughout the project lifecycle. Agile thrives in dynamic environments where requirements are likely to evolve, such as software development, product development, and marketing campaigns.
- For example, developing software for a medical device that requires strict regulatory compliance would typically use the Waterfall methodology. This is because it demands detailed, upfront specifications and rigorous testing, with minimal room for changes after development begins. Conversely, creating a new feature for a social media platform is better suited for Agile. This allows developers to build and release features incrementally, incorporating user feedback and adapting to evolving trends.


Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.
- Software Developer is responsible for the design, development, and maintenance of software applications. This involves translating business requirements into efficient and reliable code, debugging and resolving software defects, and implementing new functionalities.
- Quality Assurance (QA) Engineer acts as the guardian of quality, designing and executing test plans, identifying and reporting defects, and ensuring the software meets established standards through both manual and automated testing.
- A Project Manager is responsible for the comprehensive oversight of project execution. This includes defining and managing the project's scope, setting and ensuring timelines and budgets are met.


Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
- Integrated Development Environments (IDEs) enhance software development by combining essential tools like code editors, debuggers, and compilers into one platform. They improve productivity with features such as syntax highlighting, code completion, and integrated testing. Examples include Visual Studio Code, IntelliJ IDEA, and Eclipse.
- Version Control Systems (VCS) enable efficient collaboration by tracking code changes, preventing conflicts, and allowing rollbacks. Git, used with platforms like GitHub, is the most popular, while Subversion (SVN) and Mercurial offer alternative approaches. Together, IDEs and VCS streamline development, ensuring code quality, efficiency, and teamwork.


What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
- Debugging:  Use systematic debugging, logging, and divide-and-conquer techniques.
- Managing Technical Debt: Refactor regularly and follow best coding practices.
- Meeting Deadlines: Use Agile methodologies and prioritize tasks effectively.
- Security Concerns: Follow secure coding practices and conduct regular security audits.
- Communication & Collaboration: Improve documentation and engage in regular team discussions.


Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
- Unit Testing: Tests individual components or functions to ensure they work correctly. Ensures code reliability early.
- Integration Testing: Checks interactions between integrated modules. Prevents data flow issues.
- System Testing: Tests the complete system as a whole. Ensures overall functionality and performance.
- Acceptance Testing: Validates if the software meets business/user requirements. Ensures readiness for deployment.


#Part 2: Introduction to AI and Prompt Engineering


Define prompt engineering and discuss its importance in interacting with AI models.
- Prompt engineering is the practice of designing and refining input prompts to optimize AI model responses.
- Its importance is:
    1. Enhances Accuracy: Well-structured prompts yield more precise answers.
    2. Improves Efficiency: Reduces the need for multiple iterations.
    3. Customizes AI Behavior: Helps tailor responses for specific needs.
    4. Maximizes AI Potential: Unlocks better insights and creativity from models.


Provide an example of a vague prompt and then improve it by making it clear, specific, and concise. Explain why the improved prompt is more effective.
- Vague prompt: 'Explain technology'
- Improved prompt: 'Explain how artificial intelligence is transforming healthcare, with examples of its applications'
- The improved prompt is more effective because:
    1. It's more specific - Focuses on AI within a particular field.
    2. It has a clear scope - Defines what to explain (impact & examples).
    3. It is concise and direct - Avoids broad or irrelevant responses.
